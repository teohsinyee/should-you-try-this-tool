# Change Index

I use this folder to record why I changed the repo, not just what changed.

This matters to me because I do not want every future update to restart the same thinking from zero.

It also matters to future maintainers or collaborators because they can understand the intent behind the repo, not just the final files.

Use:

- `*.prd.md` for what I wanted and why it mattered
- `*.decision.md` for the tradeoffs and the final choices
- `*.spec.md` for the rules future updates should follow
- `*.logs.md` only when failures, friction, or lessons are worth keeping

## Naming Convention

Use date-prefixed filenames so changes sort naturally:

```text
YYYY-MM-DD-change-name.prd.md
YYYY-MM-DD-change-name.decision.md
YYYY-MM-DD-change-name.spec.md
YYYY-MM-DD-change-name.logs.md
```
